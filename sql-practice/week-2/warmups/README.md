# Week 2: Warm-ups

Short SQL exercises (about 30 minutes) done before each lesson, on the Pagila database.

| File | What it does |
| --- | --- |
| [1-customer-spending.sql](1-customer-spending.sql) | Customers who spent more than 150, filtered with `HAVING` |
| [2-film-rating.sql](2-film-rating.sql) | Film count, average length and long films per rating, using `FILTER` |
| [3-monthly-revenue.sql](3-monthly-revenue.sql) | Monthly revenue per store with subtotals and a grand total using `ROLLUP` |
| [4-number-of-different-films.sql](4-number-of-different-films.sql) | Rentals, distinct films and latest rental for customers with 60+ rentals |
| [5-montly-rental-customer.sql](5-montly-rental-customer.sql) | Monthly rentals, distinct customers and rentals per customer |
| [6-each-store-returns.sql](6-each-store-returns.sql) | Late, on-time and unreturned rentals per store |
| [7-rentals-payment-full-join.sql](7-rentals-payment-full-join.sql) | Monthly rentals and payments, keeping months with only one, using `FULL JOIN` |
| [8-customers-with-3-categories.sql](8-customers-with-3-categories.sql) | Customers who rented Horror, Comedy and Action films |
